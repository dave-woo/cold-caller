# Seminar Cold Caller

A single-page tool for calling on students at random during class.

**Open it here: https://dave-woo.github.io/cold-caller/**

- Paste a roster (one name per line, straight from a spreadsheet or LMS export)
- Tap names to mark students absent; absent students are never called
- "Everyone once before repeats" mode cycles through the whole class before anyone is called twice, or switch to fully random
- Skip a student and put them back in the pool, or mark them absent and redraw
- Press the space bar to call on someone

## Privacy

The roster is saved only in the browser you use (localStorage). It is never uploaded or stored in this repository.

## Use it

Visit https://dave-woo.github.io/cold-caller/ in any browser, or download `index.html` and open it directly.
